# Data-Structures-and-Algorithms-Project
Data Structures and Algorithms 2020-2021 CEID spring semester course project in C. The repository includes the necessary code to implement MergeSort, QuickSort, HeapSort, CountingSort,
Binary Search, Interpolation Search , Binary Interpolation Search (with its improvements). Additionally code to implement data structures such as AVL Tree, Hash table with basic functions
such as creating the data structure, Inserting, Deleting and Searching Data is included.
